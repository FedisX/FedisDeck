# FedisDeck

Open, edit and save documents in one app: Word, Excel, PowerPoint, PDF,
HTML, Markdown, text and pictures. Everything stays on your computer.

This page only hosts the app downloads and its updates.

## Download

Get the files from the latest release:
**[Releases > Latest](https://github.com/FedisX/FedisDeck/releases/latest)**

| Computer | File |
|---|---|
| Windows (64-bit) | `fedisdeck-windows-amd64.exe` |
| Mac with an Apple chip (M1 or later) | `FedisDeck-Mac-M-chip.dmg` |
| Linux (64-bit Intel/AMD) | `fedisdeck-linux-amd64.AppImage` (coming soon) |

## Install

**Windows**: open `fedisdeck-windows-amd64.exe`. If Windows warns:
More info > Run anyway.

**Mac**: open the DMG and drag FedisDeck to Applications. The first time,
right-click FedisDeck > Open. If macOS still blocks it: System Settings >
Privacy & Security > Open Anyway.

**Linux**: make the file executable and open it:
`chmod +x fedisdeck-linux-amd64.AppImage && ./fedisdeck-linux-amd64.AppImage`.
If it does not start on Ubuntu, install FUSE: `sudo apt install libfuse2`
(on 24.04: `sudo apt install libfuse2t64`).

## Updates

FedisDeck checks this page for new versions. With About > Automatic updates
on, it installs them when you close the app; with it off, it asks first.
Every update is signed, and the app refuses any update that is not.
